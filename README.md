# dataview

Удобный и быстрый просмотрщик SQLite, PostgreSQL и MySQL баз данных, написанный на Rust.

## 🚀 Возможности
- Поддержка SQLite, PostgreSQL, MySQL
- Просмотр списка таблиц
- Сортировка данных по клику на заголовок колонки
- Экспорт данных в CSV

## 📦 Скачать
Перейдите в раздел [Releases](https://github.com/sh4rpy-cc/dataview/releases) и скачайте последнюю версию `.exe`.
